# 한국 상장사 분석 실행

저장소 루트의 `AGENTS.md`와 `SKILL.md`가 공통 실행·완료 계약이다. Claude도 같은 오케스트레이터와 호스트 응답 경로를 사용한다. 별도의 확률 정책이나 완료 기준을 만들지 않는다.

- 최초 실행 준비: `docs/RUNBOOK_KR_LIVE.md`의 필요한 절을 읽고 resolver로 run.yaml을 생성한다. 예시 런은 형식 참고이며 다른 회사의 수치·확률·통과 상태를 복사하지 않는다.
- 자료 보완·중단 재개·보고서 완주: `docs/RESEARCH_CAMPAIGN_RUNBOOK.md`. 출력된 작업지시를 직접 읽고 원문 조사·응답 작성 후 같은 작업공간에서 재개한다. 별도 LLM API 키나 사용자가 작성한 JSON을 요구하지 않는다.
- 대상기업 확률은 자기 실현 이력과 허용된 전향 증거로 보정한다. 다른 회사 영업실적을 타깃 확률 표본으로 쓰지 않는다. 비교기업 이익률 조정은 가정 추정에만 사용한다.
- 현재가·증권사 목표/실적 전망은 감사와 내재가치 확정 이후에만 읽는다. 감사 전 수집하라는 오래된 예시는 따르지 않는다.
- 최종 전달본은 같은 실행의 검증된 불변 보고서와 SVG 두 장이다. 최신 별칭·보고서 문자열·부분 가치만으로 완료를 선언하지 않는다. 숫자를 대화에서 다시 계산하거나 고쳐 쓰지 않는다.
