# 대한항공 분석 실행 계획

기준일 2026-09-13. 2025 사업보고서와 2026 반기 연결재무제표, 합병 공시를 먼저 읽는다. 연결/별도 실적을 구분하고 여객·화물·항공우주·기타의 경제 경로와 아시아나 통합·리스·CAPEX·비지배지분·희석을 반영한다. 현재가와 증권사 목표가는 내재가치 확정 뒤 비교한다.

항공운송 업종명을 새 보편규칙으로 만들지 않는다. 리서치로 확인한 `capacity × utilization × unit price`, 높은 고정비·재투자, 경제적 리스, 다중 만기 금융청구권과 재무곤경 비선형성에 적용하는 **구조 공통 계약**과 기존 결정론적 DCF 연결을 검증한다. 공통 계산·감사 코드에는 대한항공·항공업 전용 명칭이나 고정값을 넣지 않고, 대한항공은 회사 profile·공시 metric mapping·자기 분기이력·자산/리스·금융 만기표만 제공하는 첫 production proof로 둔다. 실제 공개 원문을 수집하고 API 원본을 만들었다고 가장하지 않는다. 자료 부족은 조사 및 명시적 추정으로 보완하고 전체 감사·보고서 생성을 확인한다.

작업: 주 담당은 원문·모델·실행·보고서, 독립 조사자는 연결재무 및 사업 드라이버, 실행 담당은 업종 계약과 공시 입력 연결을 맡는다. 수치와 완주 결과를 얻기 전 완료를 주장하지 않는다.

## 2026-09-14 가치평가 재설계

기존 6개 연간 영업이익률 이력과 반기 조건값을 결합한 nearest-anchor 시나리오 확률, 시나리오별 0원 하한 및 목표가 일률 할인 방식은 최종 투자판단에 사용하지 않는다. 기존 산출물은 감사 이력과 legacy 회귀 비교로만 보존한다.

구현 정본은 [용량·가동률·단가형 고정비 사업의 범용 연속분포 APV·재무곤경 가치평가 설계](KOREAN_AIR_DISTRIBUTIONAL_APV_DESIGN.md)다. 동일 경제범위의 분기 driver panel, 재귀적 상관경로, 사업별 SOTP·APV, 차입금·리스 만기와 차환·증자·구조조정 waterfall, 구주주 가치분포, P50 중앙 적정가 및 요구수익률 기반 매수가를 하나의 불변 실행으로 연결한다. 적용 여부는 업종이 아니라 구조 적합성 게이트로 판정한다. 항공·해운·운송·호텔·일부 인프라 중 공통 현금흐름 생성식과 청구권 구조를 충족하는 segment만 공통 route를 사용하고, 규제자산·계약백로그·NAV·자원옵션이 핵심인 segment는 별도 evaluator로 fail-closed route한다. 새 설계의 전체 검증이 통과하기 전에는 20,813원 목표가와 15,600원 매수가를 재사용하지 않는다.
