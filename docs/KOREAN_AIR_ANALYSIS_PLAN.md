# 대한항공 분석 실행 계획

기준일 2026-09-13. 2025 사업보고서와 2026 반기 연결재무제표, 합병 공시를 먼저 읽는다. 연결/별도 실적을 구분하고 여객·화물·항공우주·기타의 경제 경로와 아시아나 통합·리스·CAPEX·비지배지분·희석을 반영한다. 현재가와 증권사 목표가는 내재가치 확정 뒤 비교한다.

항공운송 업종은 기존 정유·소매업 요구사항에 억지로 넣지 않는다. 항공운송의 수요·공급·운임·연료·기단·리스·투자 근거를 적용하는 **항공사 공통 업종 계약**과 기존 결정론적 DCF 연결을 검증한다. 공통 계산·감사 코드에는 대한항공 이름이나 고정값을 넣지 않고, 대한항공은 회사 profile·공시 metric mapping·자기 분기이력·금융 만기표만 제공하는 첫 production proof로 둔다. 실제 공개 원문을 수집하고 API 원본을 만들었다고 가장하지 않는다. 자료 부족은 조사 및 명시적 추정으로 보완하고 전체 감사·보고서 생성을 확인한다.

작업: 주 담당은 원문·모델·실행·보고서, 독립 조사자는 연결재무 및 사업 드라이버, 실행 담당은 업종 계약과 공시 입력 연결을 맡는다. 수치와 완주 결과를 얻기 전 완료를 주장하지 않는다.

## 2026-09-14 가치평가 재설계

기존 6개 연간 영업이익률 이력과 반기 조건값을 결합한 nearest-anchor 시나리오 확률, 시나리오별 0원 하한 및 목표가 일률 할인 방식은 최종 투자판단에 사용하지 않는다. 기존 산출물은 감사 이력과 legacy 회귀 비교로만 보존한다.

구현 정본은 [항공사 범용 연속분포 APV·재무곤경 가치평가 설계](KOREAN_AIR_DISTRIBUTIONAL_APV_DESIGN.md)다. 동일 경제범위의 분기 driver panel, 재귀적 상관경로, 사업별 SOTP·APV, 차입금·리스 만기와 차환·증자·구조조정 waterfall, 구주주 가치분포, P50 중앙 적정가 및 요구수익률 기반 매수가를 하나의 불변 실행으로 연결한다. 네트워크 항공사·저비용 여객사·화물 항공사는 공통 route를 사용하되 프로필별 필수 모듈을 달리하고, 공항·항공기 제조·리스·종합물류 사업은 별도 segment로 fail-closed route한다. 새 설계의 전체 검증이 통과하기 전에는 20,813원 목표가와 15,600원 매수가를 재사용하지 않는다.
