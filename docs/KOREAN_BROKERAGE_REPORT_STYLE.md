# 한국 증권사형 투자보고서 작성 계약

## 목적

PRISM의 최종보고서를 실행 로그가 아니라 투자자가 첫 화면에서 판단할 수 있는 한국어 투자보고서로 만든다. 독자가 먼저 여는 산출물은 인쇄 가능한 독립형 HTML이며, Markdown은 계산·처리 기록을 보존하는 감사용 부속자료다. `투자 요약`은 별도 서문이 아니라 보고서의 핵심 본문이며, 가치평가·위험·출처는 그 판단을 검증하는 지원 구역이다.

## 공통 구조

1. 첫 화면이 곧 투자보고서다. 별도 요약 뒤에 개발자용 본문을 두지 않는다.
2. 결론형 제목 아래에 투자판단, 현재가, 기준 내재가치, 가치평가 범위, 기준일을 한 번에 보여준다.
3. `한 문장 결론`은 무엇이 가치의 핵심 동인이고 현재가에서 무엇을 확인해야 하는지 밝힌다.
4. `투자포인트`는 세 개 이내로 제한하고 사실, 가치평가 해석, 남은 제약을 연결한다.
5. `판단 변경 조건`은 상방 확인, 하방 훼손, 행동 가능 조건을 분리한다.
6. 가치평가 산식과 핵심 가정은 바로 뒤에서 검증할 수 있게 하되 첫 화면의 판단을 반복하지 않는다.
7. 원문 출처는 직접 링크로 제공하고, 인공지능 인사이트와 결정론적 계산을 분리한다.
8. 33단계 상태·해시·기술 식별자는 접힌 감사 부록에만 둔다.
9. 발행 스크립트와 지속적 통합 검사는 HTML 본문, Markdown 부속자료, SVG 2장이 같은 실행 결과에서 생성됐는지 함께 확인한다.
10. 화면과 인쇄물의 섹션 제목·표 머리글에는 `Freeze`, `PASS`, 단계 ID 같은 내부 용어를 노출하지 않는다.

## PRISM 적용 경계

- 증권사 투자의견·목표가는 내재가치 고정 후 비교 대상으로만 사용한다.
- 실제 해결 이력 기반 확률 보정 또는 진입 규칙이 없으면 임의의 매수 등급·매수 가격을 만들지 않는다.
- 샘플의 문장, 숫자, 표, 전망은 투자 근거로 전용하지 않는다. 투자 근거는 회사 공시·기업설명자료·허용된 시장자료와 동일 실행의 결정론적 결과에 한정한다.
- 보고서 요약과 하위 가치평가·위험·출처 구역은 같은 불변 실행 데이터를 사용해야 한다.
