# Capacity E2E Sub-Agent Roles

- **Runtime Integration Agent** — provider contracts, canonical adapter ordering and fail-closed execution.
- **Economic Integrity Agent** — Capacity eligibility, baseline incrementality, CAPEX/ramp consumption and double-count boundaries.
- **Risk Agent** — preserve mandatory Beta/WACC provider execution and prohibit analyst-prior substitution.
- **QA/Release Agent** — focused integration, full regression, OCI regression and exact-SHA acceptance.
- **Reporting Agent** — deterministic verified report form with stage and hash evidence.
- **PM/Integrator** — scope control, review resolution, merge and post-merge main verification.
