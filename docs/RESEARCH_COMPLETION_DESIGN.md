# 자료 보완부터 투자보고서 완주까지

## 목표와 완료 기준

사용자 요구는 자료 부족을 이유로 분석을 반복 중단하지 않고, 검색과 근거 있는 추정으로 처음부터 최종 보고서까지 완성하는 것이다. 함수별 테스트 통과나 보고서 문자열 존재만으로 완료하지 않는다. 전체 실행·감사·가치 확정을 거쳐 투자보고서, 시각 자료, 원문 출처 및 동일 실행에 묶인 불변 배포 묶음이 실제 존재해야 완료다. 부분 사업가치는 전체 기업가치 완주로 판정하지 않는다.

## 변경 영향과 실패 조건

| 변경 | 영향 | 오류 방지·수용 기준 |
|---|---|---|
| 직접 자료 → 독립 자료·증권사 단서 → 비교기업 조정 → 범위 추정 | 조사 응답·캐시·추정 반입 | 같은 실패 답변도 다른 조사 방식으로 재시도; 무근거 기본값·미확인 사실 승격 금지 |
| 비교기업 이익률 | 영업이익·현금흐름·가치 | EBIT/EBITDA·회계기준·기간 통일, 명시적 가중치·조정폭, 출처와 재현 가능한 계산 보존 |
| 계산 중단 복구 | LLM 역할·입력·전체 실행 | 중단 단계·원인·다음 행동을 호스트에 전달; 수정 입력으로 재실행하며 통과 상태는 복사하지 않음 |
| 보고서 생성 | 상태 저장·투자자 문안·배포 | 임시 저장소 삭제 문제 해결, 실제 사용한 입력으로 보고서 식별, 오래된 문안 검토, 불변 파일 검증 |
| 조건부 결론 | 확률·투자의견 | 보정확률 부재는 시나리오 평가로 표현; 확률가중 기대값·매수가를 임의 생성하지 않음 |

비교기업의 성숙도·가동률·가격·원가·감가상각 차이는 분석자가 근거를 들어 조정한다. 고정 감점이나 자동 수렴 연도는 두지 않는다. 손실 사업의 음수 이익률도 허용한다. 비교기업 영업실적은 대상기업 시나리오 확률의 학습 표본으로 전용하지 않는다.

## 작업 경계와 의존성

A는 비교기업 이익률 순수 계산 모듈과 전용 테스트, B는 실행 복구·보고서 완주 조정자와 전용 테스트를 소유한다. 주 담당 C는 조사 응답 계약, CLI 연결, 투자보고서 표현, 문서와 통합 테스트를 소유한다. A/B는 독립 병렬 개발하며 공개 인터페이스 확정 뒤 C에서 통합한다. 기존 원본 실행 폴더는 보존하고 별도 작업 복사본에서 추정값과 역할 응답을 반영한다.

## 경계

호스트 ChatGPT/Claude가 원문 검색·이해와 가정 선택을 수행하고 코드가 계산·검증·기록을 담당한다. 자료 부족은 보완 요청이며 최종 투자판단이 아니다. 조사 예산 소진이나 호스트 응답 대기는 재개 상태로 보존한다. 회계 모순·변조·권한 문제를 숫자로 덮거나 감사 실패를 완료로 바꾸지 않는다. 국가별 공시 수집 어댑터 미구현은 별도 구현 과제이며 KR 실행 테스트를 미국 기업 실증으로 표현하지 않는다.

## 기대효과와 검증

직접 수치가 없어도 비교기업 조정값을 기존 계산 입력으로 전달하고, 역할 답변·문안 보완 후 실제 보고서까지 도달하는 통합 사례로 검증한다. 입력 변경이 수치와 최종 산출물에 전달되는지, 실패 시 기존 정상 보고서가 보존되는지, 재실행 시 같은 입력을 재사용하는지 확인한다. 이는 실행 완결성 검증이며 투자 예측 정확도 향상률의 증거는 아니다.
