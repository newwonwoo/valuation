# 모니터링 트리거 작성 양식

## 원칙
- 트리거는 **계층 이동**을 판정한다. 주가 등락은 트리거가 아니다.
- 출처 등급 ①공시원문 ②회사IR 만 신호로 채택한다.
- 신호가 없으면 "변동 없음"으로 끝낸다. 없는 신호를 만들지 않는다.

## 트리거 구조

```
### [코드] 트리거명   【최우선 / 리스크】
- 현재 상태: (숫자와 기준일)
- 트리거   : (어떤 공시가 뜨면)
- 판정     :
    조건A → ② 확인. 목표 ____원
    조건B → ③ 진입. 목표 ____원
- 역트리거 : (언제까지 무공시면 하향)
```

## 필수 포함 트리거 유형

1. **핵심 계약 공시** — 퀄 통과 후 PO 미공시 기간을 반드시 카운트한다
2. **계약부채 분기 확인** — 임계값을 숫자로 명시
3. **가이던스 변경** — 상향/하향 모두
4. **희석 요인** — 전환사채·교환사채 행사
5. **재무 임계** — 이자보상배율 하한

## 일일 보고 양식

```
[NEXT SIGNAL] YYYY-MM-DD
<종목>  주가 ____원 (전일비 __%)
  신규공시: (없음 / 내용)
  트리거  : __ 발동 / 없음
  계층    : ① / ② / ③   (이동: 없음 / ↑ / ↓)
판정: 변동 없음 / 밸류에이션 갱신 필요(사유)
```

## 캘린더 고정
- 분기 잠정실적 공시 → 계약부채·수주잔고 1차 검증
- 분기보고서 제출 → 원문 재확인
- 단일판매·공급계약 공시 → 상시
