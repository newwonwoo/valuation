## 해석

기준 주당가치는 3,671.77원, 상방은 36,672.64원입니다. 하방의 부채 차감 후 잔여가치는 주당 -26,760.88원이며, 유한책임을 반영한 주식가치는 0원으로 표시합니다. 0원은 해당 가정하의 평가 하한이며 파산 확률이나 실제 거래가격 예측이 아닙니다. 시나리오 확률은 보정하지 않았으므로 단일 확률가중 목표가를 제시하지 않습니다.

공시를 토대로 모델을 만들었지만 가치에 직접 투입되는 미래 현금흐름·말기 가정은 모두 분석가 추정입니다. 감사의 근거 구성 지표도 추정 100%로 분류합니다. 이는 실제 재무제표까지 추정이라는 의미가 아니며, 미래 가치 계산 입력과 과거 공시 사실을 구분한 결과입니다. 기준값이 현재가보다 크게 낮다는 사실을 곧바로 동일 폭의 주가 하락 전망으로 읽어서는 안 됩니다.

감사의 차단 항목은 통과했습니다. 비차단 경고는 공시 직접 입력 비중, 추정 입력 집중, 가치의 높은 민감도입니다. 특히 상방 항공운송 가치의 할인율·영구성장률·현금흐름 수준 변경 민감도는 약 21~32%로 나타납니다. 정확한 충격 크기와 결과는 valuation_sensitivity.json에 기록했습니다. 이 값들은 확률이나 예측 오차 범위가 아닙니다. 자동 민감도는 세 시나리오 중 두 개에서만 일부 DCF 부문을 재구성했으며, 하방과 기준 항공운송을 포함한 전체 조합을 포괄하지 않습니다. 모든 가정의 안정성이 검증됐다는 뜻은 아닙니다.

주가와 증권사 자료는 최초 내재가치 동결 뒤에만 비교했습니다. 이후 model.json과 underwriting.yaml의 SHA256은 최초 동결 전후 동일합니다. 공개 증권사 비교는 확인한 7월 보고서 두 건으로 최신 시장 전체 컨센서스를 뜻하지 않습니다.
